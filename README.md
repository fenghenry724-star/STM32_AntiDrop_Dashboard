# AntiDrop_Dashboard (防掉压智能仪表盘)

## 项目简介 (Introduction)
本项目终极目标为开发一款基于STM32的“两轮电动车防掉压智能仪表盘系统”，旨在解决真实物理场景下，电机大电流启动导致电池内阻分压、仪表盘瞬间“虚电跳格”的痛点。

## 当前版本进度 (Version Status)
**当前版本：v0.1 (底层电机驱动与控制阶段)**
目前已完成底层直流电机非阻塞驱动模块的搭建、多文件工程解耦以及物理硬件实测。后续将在此基础上迭代 ADC 高精度采集与滑动滤波算法。

## 核心技术点 (Core Features)
*   **工程解耦**：采用分层多文件架构 (`motor.c`, `motor.h`)，彻底分离底层驱动与上层业务逻辑。
*   **非阻塞状态机**：彻底摒弃 `HAL_Delay()`，基于 `HAL_GetTick()` 构建系统时间戳，实现多任务并发调度，保证系统微秒级实时响应。
*   **安全限幅**：底层接口实现参数防越界保护，增强系统鲁棒性 (Robustness)。

## 硬件架构 (Hardware Architecture)
*   **MCU**: STM32F103C8T6 核心板
*   **驱动**: L298N 电机驱动模块
*   **供电**: 12V 独立动力电池 + 独立 3.3V/5V 逻辑供电（已实现物理共地）
